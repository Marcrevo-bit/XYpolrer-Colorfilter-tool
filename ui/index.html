① 匹配条件 名称

"无运算 + 单位 d" = 今天（如 ageM: d）；ageM: 1 d = 昨天；ageM: < 0 d = 修改时间在未来。
子范围例：dateM: dw 6-7 周末修改 · dateC: h 8-10 上午8-10点创建。日期类只在列表生效，不上目录树。
路径 > 260 字符会导致复制/删除异常，建议高亮预警。

③ 多档渐变 ||

同一条规则内用 || 串多个「条件>颜色」，从上往下第一条命中的生效，适合做程度渐变（如按修改时间由近到远、按体积由大到小）。

④ 条件组合器 AND / OR / NOT

把多个原子条件组合成一条规则。;=OR（同档内），AND=并且，!=取反。 XYplorer 颜色过滤器不支持正则表达式，只有 * 和 ? 两个通配符。

⑤ 批量生成 按扩展名建整套配色

每行一组，格式 名称|扩展名模式（用 ; 分隔多个扩展名）。 颜色自动从当前配色方案依次取用。

一行规则结构
[+] ["标题"] [T:|L:|B:] 选择器: 模式 [d|f] [|开关] [//注释] >前景色[,背景色]

运算符 == < > <= >=，区间 min - max / -< / >- / ><

布尔 ;=OR · AND/&=AND（前后留空格）· !/NOT=NOT · "…"=精确匹配

age 单位 y年 q季 m月 w周 d天(默认) h时 n分 s秒（数字与单位间必须有空格）

date 单元 y q m dw(周一=1) dy d h n s ms

size 单位 B KB MB GB TB PB（可小数、可加空格）

属性 readonly(r) hidden(h) system(s) directory(d) archive(a) normal(n) temporary(t) junction(l) compressed(c) offline(o) encrypted(e) indexednot(i) pinned(p) unpinned(u)

高级 注释区 //[m|n]|[filter:预过滤]|[filternot:排除]|注释； m=合并下条文字色，n=只着色名称列
